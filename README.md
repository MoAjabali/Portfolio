# Portfolio Project

A modern, bilingual (English/Arabic) portfolio website built with Next.js 15, React 19, Tailwind CSS 4, and the latest shadcn/ui components powered by Base UI. Optimized for SEO with structured data, sitemap generation, and PWA support.

## Features

### Core Features
- **Responsive Design**: Mobile-first layout that works on all screen sizes
- **Bilingual Support**: English (LTR) and Arabic (RTL) language toggle via LanguageContext
- **Modern UI Components**: Built with the latest shadcn/ui v4 + Base UI (Radix-free architecture)
- **Smooth Scroll Animations**: Section reveal animations on scroll using custom useScrollAnimation hook
- **Contact Form**: EmailJS integration with Zod validation and react-hook-form
- **Toast Notifications**: Success/error feedback with Base UI Toast system
- **Social Links**: LinkedIn, Twitter/X, GitHub, Facebook integration

### SEO Optimizations
- **Comprehensive Meta Tags**: Per-page and global SEO meta tags with `next/head`
- **Open Graph Protocol**: Rich social sharing cards for Facebook, LinkedIn, etc.
- **Twitter Cards**: Summary_large_image format for Twitter/X
- **Structured Data (JSON-LD)**: Schema.org Person and WebSite types for rich snippets
- **Sitemap Generation**:

  - Dynamic API: [src/pages/api/sitemap.js](file:///home/moajabali/main/Programing/Full-Stack/myProject/Frontend/Portfolio/src/pages/api/sitemap.js)
  - Build script: [sitemap.js](file:///home/moajabali/main/Programing/Full-Stack/myProject/Frontend/Portfolio/sitemap.js)
  - Config: [next-sitemap.config.js](file:///home/moajabali/main/Programing/Full-Stack/myProject/Frontend/Portfolio/next-sitemap.config.js)
- **Robots.txt**:
  - Static: [public/robots.txt](file:///home/moajabali/main/Programing/Full-Stack/myProject/Frontend/Portfolio/public/robots.txt)
  - Dynamic API: [src/pages/api/robots.js](file:///home/moajabali/main/Programing/Full-Stack/myProject/Frontend/Portfolio/src/pages/api/robots.js)
  - Build script: [robots.js](file:///home/moajabali/main/Programing/Full-Stack/myProject/Frontend/Portfolio/robots.js)
- **PWA Manifest**:
  - Runtime: [public/manifest.json](file:///home/moajabali/main/Programing/Full-Stack/myProject/Frontend/Portfolio/public/manifest.json)
  - Build script: [manifest.js](file:///home/moajabali/main/Programing/Full-Stack/myProject/Frontend/Portfolio/manifest.js)
- **Canonical URLs**: Proper canonical and hreflang tags for multilingual SEO
- **Security Headers**: X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy
- **Image Optimization**: Automatic AVIF/WebP formats via Next.js Image

## Getting Started

### Prerequisites
- Node.js 18.17+ or 20+
- npm / yarn / pnpm / bun

### Installation

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

### Environment Variables

Create a `.env.local` file in the project root:

```env
# EmailJS (required for contact form)
NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key

# Site URL (used for SEO, sitemap, OG tags)
NEXT_PUBLIC_SITE_URL=https://moajabali.com
```

### Development

```bash
npm run dev
# -> http://localhost:3000
```

### Production Build

```bash
# 1. Build Next.js app and auto-generate SEO files (postbuild hook)
npm run build

# 2. Start production server
npm start
```

The `postbuild` script automatically runs `sitemap.js`, `robots.js`, and `manifest.js` to regenerate fresh SEO assets in `public/` after every build.

### Standalone SEO Generation

Generate SEO files without a full build:

```bash
# All SEO files
npm run generate:seo

# Individual files
npm run generate:sitemap   # public/sitemap.xml
npm run generate:robots    # public/robots.txt
npm run generate:manifest  # public/manifest.json
```

### Lint

```bash
npm run lint
```

## Notes on the shadcn/ui v4 + Base UI Migration

This project now uses the **latest shadcn/ui v4** backed by **@base-ui/react** instead of Radix UI. Key differences you'll see in the codebase:

- **No dedicated `form` component**: Old shadcn `Form`, `FormField`, `FormItem`, `FormControl`, `FormLabel`, `FormMessage` wrappers are no longer included. Instead, the contact form in [contact-section.js](file:///home/moajabali/main/Programing/Full-Stack/myProject/Frontend/Portfolio/src/components/sections/contact-section.js) uses react-hook-form's `register()` pattern directly with raw [input.jsx](file:///home/moajabali/main/Programing/Full-Stack/myProject/Frontend/Portfolio/src/components/ui/input.jsx), [textarea.jsx](file:///home/moajabali/main/Programing/Full-Stack/myProject/Frontend/Portfolio/src/components/ui/textarea.jsx), and [label.jsx](file:///home/moajabali/main/Programing/Full-Stack/myProject/Frontend/Portfolio/src/components/ui/label.jsx). Validation errors are rendered inline from `formState.errors`.
- **`@base-ui/react/*` primitives**: Input, Button, Toast now extend `@base-ui/react/input`, `@base-ui/react/button`, `@base-ui/react/toast` respectively.
- **`components.json`**: Confirmed on Base UI engine.
